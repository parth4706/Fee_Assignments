# Fee Assignments

This repository contains the Fee coursework and practice projects.

## Contents

- `Projects/project1`: React portfolio grid.
- `Projects/project2/shopping-site`: ShopSphere shopping interface.
- `sem3/first`: HTML, CSS, and JavaScript exercises.
- `sem3/Login_Page`: Login page exercise.
- `sem3/React/vite-project`: React product showcase exercise.
- `shopping-site`: React and Vite starter exercise.

## Running a React project

From any project directory containing `package.json`, run:

```bash
npm install
npm run dev
```

Production validation is available with `npm run lint` and `npm run build`.
